#  Pokédex

Pokédex responsiva desenvolvida com **HTML, CSS e JavaScript**, utilizando a **PokéAPI** para obter informações dos Pokémon em tempo real.

##  Funcionalidades

- 🔎 Pesquisa de Pokémon por nome ou número
- 🖼️ Exibição da imagem oficial
- 📱 Interface responsiva
- 🎮 Design inspirado em uma Pokédex real

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PokéAPI

## API

Os dados dos Pokémon são obtidos através da *PokéAPI*, uma API pública que fornece informações sobre Pokémon.

##  Objetivo

Projeto desenvolvido durante meus estudos para praticar **JavaScript, consumo de APIs, requisições HTTP, manipulação do DOM e desenvolvimento de interfaces responsivas**.
